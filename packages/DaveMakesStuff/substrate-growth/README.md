# Substrate Growth

A bundle of blocks for generating recursive growth patterns along an input graph.

[Watch the Tutorial Video]( https://youtu.be/68-ACunKmus)

## Installation

Clone this repo or copy the package folder into your nTop workspace:

```bash
git clone https://github.com/nTopology/Utilities-community.git
```

The package lives at `packages/DaveMakesStuff/substrate-growth/`.
