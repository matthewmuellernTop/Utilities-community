# Electric Ducted Fan Blended Wing Body

Vlad the Inhaler is an aircraft that was designed, built, and flown by nTop's 2026 summer interns 

## Installation

Clone this repo or copy the package folder into your nTop workspace:

```bash
git clone https://github.com/nTopology/Utilities-community.git
```

The package lives at `packages/matthewmuellernTop/electric-ducted-fan-blended-wing-body/`.

## Usage

1. Open the provided `.ntop` file in nTop 5.54.
2. Connect your input geometry / fields to the exposed inlets.
3. Tune parameters. Export via the standard nTop exporters.

## Inputs & outputs

| Name | Type | Notes |
|------|------|-------|
| `input_1` | Body | Required. |
| `output_1` | Implicit Body | Main result. |
